# Kiro Hackathon

A simple one-page "Hello World" website.

## Contents

- `hello-world-website/` — the site
  - `index.html` — page markup
  - `styles.css` — styling (centered card on a gradient)
  - `script.js` — click a button to show a random greeting

## Running it

Open `hello-world-website/index.html` in any browser. No build step or server required.
